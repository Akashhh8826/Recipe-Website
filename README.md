# Recipe-Website
# 🍽️ Recipe Book Website

A simple and responsive Recipe Book website built using HTML and CSS. This project showcases various Indian dessert recipes with ingredients, preparation steps, and attractive food images.

## 📸 Preview

The website includes:

- Modern navigation bar
- Multiple recipe sections
- Recipe images
- Ingredients list
- Step-by-step cooking procedures
- Footer section

### Featured Recipes

- Gulab Jamun
- Raj Bhog
- Rasmalai
- Shahi Tukda

## 🚀 Technologies Used

- HTML5
- CSS3

## 🔧 Installation & Usage

1. Clone the repository:

```bash
git clone https://github.com/Akashhh8826/Recipe-Website.git
```

2. Navigate to the project folder:

```bash
cd Recipe-Website
```

3. Open `index.html` in your browser.

Or use VS Code Live Server:

```bash
Right Click → Open with Live Server
```
